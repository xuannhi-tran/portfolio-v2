Hello

I'm Nhi, a third-year Software Engineering student at the University of Sydney. I build full-stack web apps and I'm looking for a software internship in Sydney.

What I build

I like building tools that solve problems I actually have: a Discord music bot for my friends' server, an expense tracker, and JobCompass, which helps students decide whether to tailor, apply or skip a job posting.

Outside of code

Outside of code I read philosophy and psychology, and there's almost always music on while I work, which is where the vinyl theme comes from.

How I work

JobCompass started as a hackathon project. I built the full app and a teammate prepared the dataset we validated it against. I've worked with React, FastAPI, Django, Next.js and PostgreSQL, and I like taking an idea all the way to a deployed app.
